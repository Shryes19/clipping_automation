# ViralCutter clips

Made with [ViralCutter](https://github.com/RafaelGodoyEbert/ViralCutter) (no API key: manual AI mode). ViralCutter ran WhisperX transcription and segment matching. The viral picks were written into its manual-mode JSON. The final 9:16 render (stacked layout, word-by-word captions, dead-air cuts, -14 LUFS audio) is `tools/render_clips.py`.

To avoid duplicating the other tools, every clip comes from the **last quarter** of each source.

Every clip has a `.txt` next to it with a ready-to-paste caption and hashtags.
